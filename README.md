# 🚀 Mini Project — W3

## Billing System (OOP-Based)

A simple billing system developed using Object-Oriented Programming. The system allows users to enter multiple products and generates a final bill with tax.

### Product Class

The `Product` class stores:

* Product name
* Product price
* Product quantity

It also calculates the total price of each product.

### Bill Class

The `Bill` class manages the products and performs:

* Product management
* Subtotal calculation
* Tax calculation
* Final total calculation
* Tabular bill display

### Features

* Add multiple products
* Enter product name, price, and quantity
* Calculate product-wise total
* Calculate subtotal
* Calculate tax
* Calculate final bill amount
* Display the bill in tabular format
